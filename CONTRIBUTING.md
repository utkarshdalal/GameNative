# Contributing to GameNative Online

Thanks for helping improve this online-focused fork of GameNative.

## Quick start

1. Use branch `develop` (not `master`) for all work.
2. Read [PLAN.MD](PLAN.MD) so changes match the fork’s online-first direction.
3. Keep upstream syncable — see [docs/UPSTREAM_SYNC.md](docs/UPSTREAM_SYNC.md).
4. Open a pull request against `develop` with a clear description.

## Scope (this fork)

In scope:

- Online / Offline install profiles
- Online status badges and matrix accuracy
- Steam online client path reliability (Bionic / Headless)
- Diagnostics for online connection failures
- Docs and compatibility reports for multiplayer

Out of scope unless discussed first:

- Anti-cheat bypasses
- Claiming full Steam Deck online parity
- Large unrelated rewrites of upstream UI/store code

## Attribution

- Core project credit belongs to [GameNative](https://github.com/utkarshdalal/GameNative) and its contributors.
- Do not add AI tool names (or similar) to contributor lists, release notes authorship, or `Co-authored-by` trailers unless a human explicitly asks for that.

## Reporting issues

Prefer actionable reports:

- game name + app id
- Offline or Online install profile
- Steam client mode / Proton if known
- what failed (boot, auth, lobby, servers, presence)
